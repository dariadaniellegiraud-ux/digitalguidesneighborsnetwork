# Digital Guides & Neighbors Network

A community program that pairs background-checked young adults (**Guides**) with seniors (**Explorers**) for patient, one-on-one tech help. This repository contains the one-page website for the program.

**Live site:** https://digitalguidesneighborsnetwork.vercel.app

## About the program

Many older adults want to video call grandchildren, back up photos, spot scams, or update a résumé, but have no patient place to ask. Guides teach in short sessions (15, 30, or 60 minutes) over Zoom or in a public place such as a library or senior center. Guides can be paid or volunteer, and volunteers earn service-hour certificates and impact letters.

## Highlights

- Guides and Explorers both complete ID and background checks
- Two-way ratings for Patience, Clarity, and Respect
- Privacy first: first name and last initial only, meetings in public places
- Optional trusted contact for Explorers, one-tap "Report a problem"
- Bronze, Silver, and Gold Guide tiers for schools and volunteers
- Local discounts for Explorers who earn good-behavior ratings

## Design approach
- Seniors first design model using WAG best practices for readability. 
- Senior-first accessibility: large type, 48px touch targets, high-contrast color pairs, visible focus states, icon plus text labels
- A warm palette built on a deep teal, cream, and amber, with a 60-30-10 color balance
- Safety shown on both sides of the network, not just one
